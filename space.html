FRONT-END DEVELOPMENT PROJECT

SPACE BLOG

A NASA-INSPIRED INTERACTIVE BLOG EXPERIENCE

A React-based space blog application that transforms traditional blog content into an interactive experience through authentication, comments, personalization, and responsive design.

Role FRONT-END Developer
Team Ema Nova | Amanda Rangel-Andres
Tools HTML5, JavaScript, React Router, context API
Primary User Group Students, technology enthusiasts, and casual readers interested in exploring engaging space-related content through an interactive and responsive experience.

Project Objective

The goal of the Space Blog project was to design and develop a responsive web application that transforms traditional blog content into an engaging space-themed experience. The project focused on creating an interactive platform where users can explore posts, authenticate into the system, leave comments, customize their experience through theme preferences, and navigate a modern, responsive interface.

Our Mission

Before development, our team focused on understanding what makes blog platforms engaging and easy to use. We explored common usability practices, responsive web design principles, authentication flows, and personalization features. Our goal was to create an experience that felt interactive rather than simply displaying static blog posts.

Main Question

How might we create a modern, responsive blog platform that encourages user interaction while making space-related content engaging and enjoyable to explore?

The Problem

Traditional blog websites often provide limited interaction beyond reading articles. Many lack personalization, responsive layouts across devices, and engaging visual themes that encourage users to continue exploring content. Additionally, maintaining consistency across multiple pages while working as a development team introduced technical challenges throughout the project.

The Solution

We developed a responsive space-themed blog that combines authentication, interactive commenting, customizable themes, and dynamically generated blog posts from an API. By integrating modern front-end technologies and reusable design components, we created an application that provides both functionality and an engaging visual experience across desktop, tablet, and mobile devices.

Key Features

Milestone 2: Building the Interactive Experience

Authentication System

Users can securely log into the application, with their username managed globally using React Context. This allows personalized interactions throughout the website and creates a more customized user experience.

Dynamic Space-Themed Blog

Blog posts are retrieved from an external API and transformed into visually engaging space-themed reports. Custom titles, categories, and formatting help create a unique reading experience centered around space exploration.

Comment System

Authenticated users can submit comments that are displayed instantly, creating a more interactive reading experience. The feature encourages users to engage with content and participate in discussions.

Individual Post Pages

Each blog post includes its own detailed page featuring formatted content, author information, comments, and a like button. This allows users to explore articles in greater depth.

Theme Customization

Users can switch between light and dark mode, with preferences automatically saved using Local Storage for future visits. This creates a more personalized and comfortable browsing experience.

Contact Page

Visitors can communicate through a contact form by submitting their name, email, and message. This provides a direct way for users to connect with the platform.

Through this project, I developed a stronger understanding of how technical implementation and user-centered design work together to create engaging digital experiences.
